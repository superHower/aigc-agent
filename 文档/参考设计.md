我已经通过本机 Chrome DevTools 的 list_pages 打开 RunningHub，并结合截图、DOM
  和 getComputedStyle 检查了首页及下方内容区。下面的颜色、字号是页面实测，不只是
  看图估计。

  一句话总结：它是“纯黑底 + 荧光黄绿强调色 + 大量视频封面”的 AI 创作内容平台，偏
  潮流、科技和专业工具气质，而不是传统蓝白色 SaaS 官网。

  ## 1. 整体设计风格

  从 UI 设计角度，我会用这几个关键词概括：

  - Dark-first 暗色优先：纯黑背景贯穿页面，让图片和视频成为视觉主角。
  - Neon Accent 荧光强调：用高亮黄绿色标记品牌、关键按钮和部分重点标题。
  - Content-first 内容优先：不是大标题配一张插画，而是直接展示模板、案例和创作入
    口。

  - 高密度、强运营：导航、活动通知、促销横幅、内容推荐同时存在，明显兼顾转化和内
    容分发。

  我的判断是：整体更接近“创作工具入口 + 流媒体内容货架”，而不是单一产品的介绍
  页。

  页面 CSS 还定义了：

  - --rh-green: #02DBA3
  - --rh-sky: #45CFFF
  - --rh-cyan: #22D3EE

  不过，“CSS 中存在”不等于“当前首页主视觉在大量使用”。当前首页最明确的品牌强调色
  仍然是 #CCFF00。

  ### 专业上怎么理解？

  它采用的是：

  > 低彩度界面底板 + 高彩度品牌点缀 + 全彩媒体内容。

  黑白灰负责保证可读性；荧光绿负责指引操作；真正丰富的色彩来自作品封面。这样可以
  避免界面本身与内容争夺注意力。

  ## 3. 字体：中英文分工，还有专门的数字字体

  实测页面不同区域使用了不同字体栈，并不是全站只有一种字体。

  ### 导航等区域

  font-family:
    "RunningHub Numerals",
    "Source Han Sans",
    system-ui;

  ### 首页推荐、内容卡片等区域

  font-family:
    "RunningHub Numerals",
    Inter,
    "PingFang SC",
    "Helvetica Neue",
    sans-serif;

  可以这样理解：

  - Source Han Sans：思源黑体，用于部分中文界面。
  - Inter：出现在内容区字体栈中，承担西文排版的设计角色。
  - PingFang SC：苹方，是相关区域的中文候选字体。
  - RunningHub Numerals：页面已加载的数字字体，字符范围限定为数字、货币及部分符
    号，不是整段中文正文的字体。

  这里需要区分：CSS 声明的字体栈不代表每个字符都由第一个字体绘制，中文、英文和数
  字可能分别落到不同字体上。

  另外，导航中的 RunningHub Logo 是图片资源，不能直接拿它的字形判断正文用的是什
  么字体。

  ## 4. 布局：横向货架，而不是瀑布流

  首页实测的主要结构是：

  顶部荧光色活动通知条
  主导航 / 搜索 / 会员 / 登录
  横向活动推荐卡片
  通栏促销 Banner
  短视频模板横向列表
  模型、Skill 等展示区
  电商创作四列卡片
  短漫剧及其他内容分区

  ### 几个重要的布局数值

  - 左侧内容边距约 80px，形成清晰的统一对齐线。
  - 顶部推荐卡片约 350px 宽，卡片之间间距 16px。
  - 顶部推荐图接近 16:9 横图。
  - 短视频卡片约 165 × 220px，接近 3:4 竖图。
  - 短视频卡片间距 8px，排列紧凑。
  - 下方电商场景采用 四列大卡片，增强案例展示感。
  - 页面向下滚动时，顶部导航仍保留在视口上方。

  一个很典型的处理是：右侧故意露出下一张卡片的一部分，并搭配箭头、暗色渐变遮罩。

  这属于横向列表的“可继续浏览暗示”，用户不用读说明就知道右侧还有内容。

  ## 6. 从专业 UI 角度，优点与不足是什么？

  ### 值得借鉴

  - 品牌识别鲜明：黑色与荧光黄绿的组合非常容易记住。
  - 内容表现力强：背景退后，作品封面成为主角。
  - 浏览效率高：横向内容货架适合快速扫视大量模板。
  - 转化入口明确：荧光色按钮在复杂内容里仍有较高辨识度。

  ### 可以优化

  以下属于我的设计评价，而不是 CSS 检测结果：

  - 首屏争抢注意力的元素偏多：活动条、多个彩色标签、促销横幅同时出现，焦点较分
    散。

  - 部分文字偏紧：推荐标题 16px 字号配 16px 行高，遇到两行标题时容易显得拥挤。
  - 标题体系不够统一：不同模块的标题尺寸、字重差异较大，模块感强于统一设计系统
    感。

  - 导航产品较多：横向导航需要额外滚动，新用户理解各产品区别的成本较高。

  ———

  如果你想学习它的设计，真正值得复用的不是“黑底加绿按钮”，而是：用克制的界面底板
  承载丰富内容，再用少量高亮色建立品牌和操作优先级。 这才是它整体视觉成立的核
  心。
