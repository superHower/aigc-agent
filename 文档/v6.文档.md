MiniMax H3 高质量视频生成模型，自部署版本，按分辨率计费：768P、1080P、2K，用 resolution 参数选择（如 "1080p"），不传时默认 768P。支持文生视频、首尾帧、最多 9 张参考图和 3 段参考音频（参考音频需搭配参考图）；支持 4–15 秒，比例可选 16:9、9:16、1:1、4:3、3:4、21:9，默认 16:9。2K 为超分增强输出，暂不支持 480P 和 4K。

from openai import OpenAI

client = OpenAI(
    base_url="https://88api.ai/v1",
    api_key="<YOUR_API_KEY>",
)

completion = client.chat.completions.create(
    model="minimax-h3",
    messages=[
        {"role": "user", "content": "Explain quantum entanglement in one paragraph."}
    ],
)

print(completion.choices[0].message.content)
替换 <YOUR_API_KEY> 替换为令牌设置中的 API Key。

实现说明（2026-11-01）

- 视频使用专用接口 POST /videos、GET /videos/{id}，而非上面的通用聊天示例。视频渠道模型固定 minimax-h3，建议地址 https://api.88api.ai/v1。多个 Key 分别建为多个视频渠道，任务平均分配，各渠道控制并发。
- 一图多提示词中，直接使用所选提示词组，每条组内提示词生成一个 MP4，无需额外填写视频描述。可选 4–15 秒、768P / 1080P / 2K。768P 支持六种比例；1080P、2K 仅支持 16:9、9:16。
- 视频仅使用上方上传的一张图片。首尾帧模式将该图作为首帧，仅支持 768P；全能参考模式将该图作为参考图。不提供额外尾帧、多参考图或参考音频上传。
- 参考图片使用 Base64 data URL，每张限 10MB，支持 PNG、JPEG、WebP。生成后下载并保存 MP4，可播放、单独下载或 ZIP 下载。
- 提交前持久化提交意图，收到上游编号后持久化编号。重启或重试继续查询原任务；提交超时且没有编号时停止，不自动重复创建。需向服务商核对该次提交结果。
- 取消停止本地等待；服务商可能继续生成并计费。站内沿用每个输出一积分的规则，管理员免站内积分；服务商费用以其账单为准。
- 使用模拟 HTTP 测试，不主动调用收费接口。
